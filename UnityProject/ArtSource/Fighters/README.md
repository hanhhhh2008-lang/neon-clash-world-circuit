The prompt requested exactly ten original adult fighters in a 5×2 grid, filled cel-shaded anatomy and distinct first-party identities, on a uniform `#00ff00` background, while excluding text, logos, existing IP, skeletons, robots, exposed joints, and placeholder bodies.

The runtime RGBA atlas is `Assets/Resources/NeonClash/Fighters/roster-atlas-v2.png`. Its chroma was removed locally using the installed `remove_chroma_key.py` helper with a soft matte and despill. The source is retained so the transformation is auditable.
